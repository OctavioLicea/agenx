## Decisiones tomadas

- **Sistema de temas para la página pública**: un tema a la vez por
  asesor (`perfiles.estilo_pagina_publica`), arrancando con Estándar
  (actual, verde bosque/caliza) y Elegance (blanco/negro/dorado,
  `Playfair Display`/`Montserrat`) — Elegance reservado para Nydia
  mientras sea la única usuaria. Arquitectura propuesta: hook compartido
  de datos (`usePropiedadPublica.js`) separado de la presentación por
  tema (`temas/estandar/`, `temas/elegante/`, cada uno con su CSS/fuentes
  propias cargadas solo si está activo + README de contexto), con
  `temas/registro.js` mapeando estilo → componente vía `lazy()`.
- **Alcance del header de Elegance recortado**: el mockup traía un menú
  de sitio completo (Propiedades/Servicios/Nosotros/Contacto) — se
  descarta, sigue siendo 1 propiedad = 1 página. Esa zona del header se
  usa para marca "TuAsesor" + logo de Nydia (pendiente de trabajo aparte
  para que rime con la estética Elegance) + fecha/hora arriba. Botón
  "Solicitar Tour" se queda.
- **CTAs se quedan en WhatsApp directo por ahora**: a Okta le gustó la
  idea de un formulario público que cree el lead directo en el CRM
  (contacto + proceso comercial), pero se difiere a Fase 2, para cuando
  se arme el módulo de leads/Proceso Comercial — implica INSERT público
  controlado (RLS, anti-spam), no es solo visual.
- **Descartado del mockup de Elegance**: sección "Clientes satisfechos"
  (logos de aliados, no aplica al negocio de Nydia) y "Recibe novedades
  exclusivas" (newsletter, sin servicio de envío configurado — en contra
  de YAGNI).
- **Mapa**: se mantiene Leaflet/OpenStreetMap embebido (ya decidido,
  gratis); se agrega solo un link "Ver en Google Maps" apuntando a
  `google.com/maps?q=lat,lng`, sin API key.
- **Trabajar por partes**: la sesión se estaba alargando (~30 min en el
  tramo de arquitectura/mockup sin código nuevo) — Okta pidió dividir el
  trabajo restante en partes concretas en vez de seguir de corrido.
  Arquitectura del sistema de temas queda como "parte 1" para la próxima
  sesión.
